# AutoBand

Wholdar's maintained version of AutoBand for Return of Reckoning. Organize your warband, recruit missing roles, manage rank and kick rules, and save your preferred setup as templates.

## Install

Download from [Idrinth](https://tools.idrinth.de/addons/autoband/), or use the [RoR addon site](https://addons.returnofreckoning.com/) when listed there. Extract the addon ZIP into `Interface\AddOns`, so it contains `AutoBand\AutoBand.mod`. Requires LibSlash.

The addon packages do not include external scripts.

## Use

Click the AutoBand icon to open the settings window. Use `/ab help` for commands. More settings that were previously available only through slash commands are now in the window.

If AutoBand's tells trigger mutes, enable Block AutoBand PMs or use `/ab nopm on`. `/ab nopm off` allows them again.

## Optional realm-rank data

For realm-rank checks, realm population stats and online-player lookups, download the two helper files from [optional](https://github.com/jmaartenson/AutoBand/tree/main/optional) and follow the [setup instructions](https://github.com/jmaartenson/AutoBand/blob/main/optional/README.md).

The poller runs outside the game and writes a small CSV file for the addon. Normal career-rank checks and warband features work without it.
